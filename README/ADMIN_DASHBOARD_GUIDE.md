# راهنمای داشبورد مدیریت (Admin Dashboard)

## مقدمه
داشبورد مدیریت یک پنل کاربری اختصاصی برای Super User (مدیر سیستم) است که امکان مدیریت کامل سیستم را بدون نیاز به استفاده از Django Admin Panel فراهم می‌کند.

## ویژگی‌های اصلی

### 1. ورود به داشبورد
- **URL ورود**: `http://127.0.0.1:8000/auth/login/`
- کاربران با دسترسی `superuser` یا `staff` به طور خودکار به داشبورد مدیریت هدایت می‌شوند
- پس از ورود موفق، به آدرس `/dashboard/admin/` منتقل خواهید شد

### 2. صفحه اصلی داشبورد (`/dashboard/admin/`)
صفحه اصلی شامل:
- **آمار کلی سیستم**:
  - تعداد کل کاربران (دانش‌آموزان و معلمان)
  - تعداد دوره‌ها (فعال و غیرفعال)
  - تعداد ثبت‌نام‌ها
  - درخواست‌های در انتظار معلمان

- **نمودارها**:
  - نمودار ثبت‌نام‌های 12 ماه گذشته
  - نمودار وضعیت ثبت‌نام‌ها (تایید شده، در انتظار، لغو شده)
  - نمودار وضعیت پرداخت‌ها

- **آمار ماه جاری**:
  - دانش‌آموزان جدید
  - دوره‌های جدید
  - ثبت‌نام‌های جدید
  - درآمد ماهانه

- **محبوب‌ترین دوره‌ها**: لیست 5 دوره با بیشترین ثبت‌نام

- **آخرین فعالیت‌ها**:
  - آخرین ثبت‌نام‌ها
  - آخرین درخواست‌های معلمان

- **دسترسی سریع**: دکمه‌های سریع برای دسترسی به بخش‌های مختلف

### 3. مدیریت کاربران (`/dashboard/admin/users/`)
امکانات:
- **مشاهده لیست کاربران** با اطلاعات کامل:
  - نام و نام خانوادگی
  - ایمیل
  - نوع کاربر (دانش‌آموز، معلم، ادمین)
  - وضعیت فعالیت
  - تایید ایمیل
  - تاریخ عضویت
  - آخرین ورود

- **فیلترها**:
  - فیلتر بر اساس نوع کاربر
  - فیلتر بر اساس وضعیت (فعال/غیرفعال)
  - جستجو بر اساس نام، نام خانوادگی یا ایمیل

- **عملیات**:
  - ویرایش اطلاعات کاربر (انتقال به Django Admin)

### 4. مدیریت دوره‌ها (`/dashboard/admin/courses/`)
امکانات:
- **مشاهده لیست دوره‌ها** با اطلاعات:
  - عنوان دوره
  - معلم
  - دسته‌بندی
  - قیمت
  - ظرفیت
  - تعداد ثبت‌نام
  - وضعیت (منتشر شده، پیش‌نویس، آرشیو)
  - فعالیت (فعال/غیرفعال)

- **فیلترها**:
  - فیلتر بر اساس وضعیت (published, draft, archived)
  - فیلتر بر اساس فعالیت (فعال/غیرفعال)
  - فیلتر بر اساس دسته‌بندی
  - جستجو بر اساس عنوان یا توضیحات

- **عملیات**:
  - ویرایش دوره (انتقال به Django Admin)

### 5. مدیریت ثبت‌نام‌ها (`/dashboard/admin/enrollments/`)
امکانات:
- **مشاهده لیست ثبت‌نام‌ها** با اطلاعات:
  - دانش‌آموز
  - دوره
  - معلم
  - تاریخ ثبت‌نام
  - مبلغ پرداختی
  - وضعیت ثبت‌نام (در انتظار، تایید شده، لغو شده، تکمیل شده)
  - وضعیت پرداخت (پرداخت شده، پرداخت نشده، پرداخت جزئی)

- **فیلترها**:
  - فیلتر بر اساس وضعیت ثبت‌نام
  - فیلتر بر اساس وضعیت پرداخت
  - جستجو بر اساس نام دانش‌آموز یا دوره

- **عملیات**:
  - ویرایش ثبت‌نام (انتقال به Django Admin)

### 6. مدیریت درخواست‌های معلمان (`/dashboard/admin/applications/`)
امکانات:
- **مشاهده لیست درخواست‌ها** با اطلاعات:
  - نام و نام خانوادگی
  - ایمیل
  - شماره تماس
  - تخصص
  - سال‌های تجربه
  - تاریخ ارسال
  - وضعیت (در انتظار، پذیرفته شده، رد شده)

- **فیلترها**:
  - فیلتر بر اساس وضعیت درخواست

- **عملیات**:
  - مشاهده و بررسی درخواست (انتقال به Django Admin)

## دسترسی به Django Admin Panel
در تمام صفحات مدیریتی، امکان دسترسی سریع به Django Admin Panel وجود دارد:
- دکمه "پنل ادمین Django" در هدر صفحه اصلی
- لینک‌های "ویرایش" در هر ردیف جدول که به صفحه ویرایش Django Admin منتقل می‌شود

## نمودارها و گزارش‌ها
داشبورد از کتابخانه Chart.js برای نمایش نمودارهای تعاملی استفاده می‌کند:
- **نمودار خطی**: ثبت‌نام‌های 12 ماه گذشته
- **نمودار دونات**: وضعیت ثبت‌نام‌ها و پرداخت‌ها

## نکات امنیتی
- فقط کاربران با دسترسی `is_superuser=True` یا `is_staff=True` به این داشبورد دسترسی دارند
- تمام صفحات با `LoginRequiredMixin` و `UserPassesTestMixin` محافظت شده‌اند
- در صورت تلاش برای دسترسی غیرمجاز، پیام خطا نمایش داده می‌شود

## ساختار URL
```
/dashboard/                           → هدایت خودکار بر اساس نوع کاربر
/dashboard/admin/                     → صفحه اصلی داشبورد مدیریت
/dashboard/admin/users/               → مدیریت کاربران
/dashboard/admin/courses/             → مدیریت دوره‌ها
/dashboard/admin/enrollments/         → مدیریت ثبت‌نام‌ها
/dashboard/admin/applications/        → مدیریت درخواست‌های معلمان
```

## راه‌اندازی و تست
### 1. ساخت superuser
```bash
python manage.py createsuperuser
```

### 2. ورود به سیستم
1. به آدرس `http://127.0.0.1:8000/auth/login/` بروید
2. ایمیل و رمز superuser را وارد کنید
3. به طور خودکار به `/dashboard/admin/` منتقل می‌شوید

### 3. مشاهده آمار
- اگر دیتای تستی ندارید، می‌توانید از دستور زیر استفاده کنید:
```bash
python manage.py seed_demo_data
```

## سفارشی‌سازی
### تغییر تعداد آیتم‌های نمایش داده شده
در فایل `dashboard/views.py`:
- آخرین ثبت‌نام‌ها: خط مربوط به `.order_by('-enrolled_at')[:10]`
- دوره‌های محبوب: خط مربوط به `.order_by('-enrollment_count')[:5]`

### تغییر رنگ‌ها و استایل
فایل تمپلیت‌ها در `templates/dashboard/` از Bootstrap 5 استفاده می‌کنند و می‌توانید کلاس‌های Bootstrap را تغییر دهید.

## پشتیبانی
در صورت بروز مشکل:
1. لاگ‌ها را در کنسول Django بررسی کنید
2. مطمئن شوید که تمام migrations اجرا شده‌اند
3. بررسی کنید که کاربر شما دسترسی superuser دارد
