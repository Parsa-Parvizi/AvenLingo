# سیستم تشخیص تداخل زمانی دوره‌ها

## توضیحات

این سیستم به طور خودکار تداخل زمانی بین دوره‌های یک زبان‌آموز را بررسی می‌کند و در صورت وجود تداخل، اجازه ثبت‌نام نمی‌دهد.

## قابلیت‌ها

### 1. استخراج اطلاعات زمان‌بندی
تابع `extract_schedule_info()` قادر است از متن فارسی فیلد `duration` اطلاعات زیر را استخراج کند:

- **روزهای هفته**: شنبه، یکشنبه، دوشنبه، سه‌شنبه، چهارشنبه، پنج‌شنبه، جمعه
- **ساعت شروع و پایان**: با فرمت‌های مختلف
  - `17 تا 19`
  - `ساعت 17 تا 19`
  - `17:30 تا 19:00`
  - با اعداد فارسی: `ساعت ۱۷ تا ۱۹`

### 2. تشخیص تداخل زمانی
تابع `check_time_overlap()` دو دوره را با هم مقایسه می‌کند و تداخل را شناسایی می‌کند:

#### موارد تداخل:
- ✅ همان روز هفته، زمان‌های مشترک
- ✅ همان روز هفته، یکی شروع می‌شود قبل از اینکه دیگری تمام شود

#### موارد عدم تداخل:
- ❌ روزهای متفاوت هفته
- ❌ همان روز، زمان‌های کاملاً جدا از هم
- ❌ زمان‌های مجاور (دقیقاً کنار هم بدون تداخل)

## مثال‌ها

### مثال 1: تداخل زمانی
```python
# دوره فعلی دانش‌آموز
course1.duration = "چهارشنبه ها ساعت 17 تا 19"

# دوره جدیدی که می‌خواهد ثبت‌نام کند
course2.duration = "چهارشنبه ها ساعت 16 تا 18"

# نتیجه: تداخل دارد ❌
# پیام خطا: "تداخل زمانی با دوره X وجود دارد..."
```

### مثال 2: عدم تداخل (روزهای متفاوت)
```python
course1.duration = "شنبه ها ساعت 17 تا 19"
course2.duration = "یکشنبه ها ساعت 17 تا 19"

# نتیجه: تداخل ندارد ✅
```

### مثال 3: عدم تداخل (زمان‌های متفاوت)
```python
course1.duration = "چهارشنبه ها ساعت 14 تا 16"
course2.duration = "چهارشنبه ها ساعت 17 تا 19"

# نتیجه: تداخل ندارد ✅
```

## نحوه عملکرد

### 1. در زمان ثبت‌نام
هنگامی که یک زبان‌آموز می‌خواهد در دوره جدیدی ثبت‌نام کند:

1. سیستم تمام ثبت‌نام‌های فعلی (pending یا confirmed) دانش‌آموز را بررسی می‌کند
2. برای هر دوره، زمان‌بندی را با دوره جدید مقایسه می‌کند
3. در صورت تداخل، پیام خطای مفصل نمایش می‌دهد

### 2. پیام خطای نمایش داده شده
```
تداخل زمانی با دوره "نام دوره" وجود دارد.
هر دو دوره در روز(های) چهارشنبه برگزار می‌شوند 
و زمان‌بندی آن‌ها با هم تداخل دارد.
لطفاً یکی از دوره‌ها را انتخاب کنید.
```

## نکات مهم

1. **فرمت duration**: برای عملکرد بهینه، فیلد `duration` باید شامل روز هفته و بازه زمانی باشد
   - ✅ خوب: `"چهارشنبه ها ساعت 17 تا 19"`
   - ❌ ضعیف: `"هفته‌ای 2 جلسه"` (قابل parse نیست)

2. **دوره‌های فاقد زمان‌بندی**: اگر فیلد duration خالی باشد یا قابل parse نباشد، بررسی تداخل انجام نمی‌شود

3. **زمان‌های مجاور**: دو دوره که دقیقاً پشت سر هم هستند (مثلاً 15-17 و 17-19) به عنوان بدون تداخل در نظر گرفته می‌شوند

## به‌روزرسانی‌های آینده (پیشنهادی)

1. افزودن فیلدهای ساختاریافته برای زمان‌بندی به جای استفاده از متن
2. پشتیبانی از چندین جلسه در هفته (مثلاً شنبه و سه‌شنبه)
3. اضافه کردن تایم‌زون برای دوره‌های آنلاین بین‌المللی
4. نمایش بهتر تداخل‌ها در پروفایل دانش‌آموز
