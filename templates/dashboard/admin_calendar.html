📅 تقویم مدیریت

کلاس‌ها تکالیف امتحان نهایی میان‌ترم کوییز
راهنمای استفاده از تقویم
نمایش رویدادها
  • کلاس‌ها کلاس‌های برگزار شده توسط معلمان با رنگ سبز نمایش داده می‌شوند
  • تکالیف تاریخ سررسید تکالیف دوره‌ها با رنگ آبی نمایش داده می‌شوند
  • امتحان نهایی آزمون‌های پایان ترم با رنگ قرمز نمایش داده می‌شوند
  • میان‌ترم آزمون‌های میان ترم با رنگ نارنجی نمایش داده می‌شوند
  • کوییز آزمون‌های کوتاه و کوییزها با رنگ بنفش نمایش داده می‌شوند
نحوه استفاده
  • کلیک روی رویداد: برای مشاهده جزئیات کامل رویداد
  • تغییر نمایش: از دکمه‌های ماهانه/هفتگی/روزانه برای تغییر نمای تقویم استفاده کنید
  • حرکت در تقویم: از دکمه‌های قبلی/بعدی برای حرکت بین ماه‌ها استفاده کنید
  • امروز: برای بازگشت سریع به تاریخ امروز از دکمه "امروز" استفاده کنید
  • زمان‌بندی: در نمای هفتگی و روزانه می‌توانید ساعت دقیق رویدادها را مشاهده کنید
نکته: تمامی رویدادهای تقویم به صورت خودکار از سیستم بارگذاری می‌شوند. برای ایجاد رویداد جدید، از بخش مدیریت دوره‌ها و کلاس‌ها استفاده کنید.
